# Slop Replacer

> Changes slop text with better ones that actually make sense in this society.

---

## Why did I even bother to make it?

- Bored. Also for [Crescent Hack Club](https://crescent.hackclub.com/)

## What does it actually do?

- `Microsoft` → `Microslop`
- `AI` → `Super Intelligence (Trump said it)`
- `GD` / `Geometry Dash` → `jumping game with rage`
- `67` (and `six seven`) → `dead Joke`
- *Pull Request with newer ones that you want to be included*

## How to install this?

1. Install a userscript manager ([Tampermonkey](https://www.tampermonkey.net/) is good)
2. Load the contents of [`tampermonkey.js`](https://raw.githubusercontent.com/MalikHw/slop-replacer/refs/heads/main/tampermonkey.js)
3. That's it!
